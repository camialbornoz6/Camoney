# Camoney

App para registrar ingresos, gastos, tarjetas de crédito (con cuotas), pagos en efectivo, débito y Mercado Pago, y ahorros en pesos y dólares.

Es una app web instalable (PWA): se abre desde el navegador y se agrega a la pantalla de inicio del celular. Los datos se guardan solo en el dispositivo de cada persona.

## Versión para compartir

En la carpeta `compartir/` hay una copia genérica de la app para pasarle a otras personas: https://camialbornoz6.github.io/Camoney/compartir/

- Categorías iniciales genéricas (sin las semanas de comida, que cada uno puede activar).
- Bienvenida en 3 pasos para cuentas nuevas: categorías, tarjetas y cuentas, y cómo se usa.
- Usa el mismo login (Firebase): cada persona tiene su propia cuenta y sus propios datos.

La app de la raíz (`index.html`) es la versión personal y no cambia.
